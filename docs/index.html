What it actually changes

Three places your frames are hiding.

Every tweak is a real, documented Windows or Fortnite mechanism — nothing exotic, nothing that can't be undone.

GPU & CPU

Power & scheduling

Forces the GPU into its high-performance state for Fortnite specifically, and gives the game's process priority over background CPU work.

  • GPU "Prefer Maximum Performance" preference
  • Hardware-Accelerated GPU Scheduling (HAGS)
  • Windows Game Mode
  • Live process priority boost
Network

Latency & jitter

Disables the two most common sources of small, avoidable input-to-server delay on a stock Windows network stack.

  • Nagle's Algorithm disabled (TCPNoDelay)
  • NetworkThrottlingIndex removed
  • Live ping / jitter / packet-loss readout
System

Prefer to build it yourself?

Build from source instead

For developers who want to read every line before running it, or modify the code.

1

Install the .NET 8 SDK

Grab it from dotnet.microsoft.com/download/dotnet/8.0 — pick the SDK (not just Runtime), Windows x64.

powershell
>dotnet --version
Confirms the SDK installed correctly — should print something like 8.0.4xx
2

Extract the project

Unzip IndoTweaks.zip somewhere simple, like C:\Dev\IndoTweaks — avoid Desktop or OneDrive-synced folders.

3

Restore & publish a standalone exe

Shift + right-click inside the folder → "Open PowerShell window here", then run:

C:\Dev\IndoTweaks
>dotnet restore
>dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -o publish
Produces publish\IndoTweaks.exe — the same kind of standalone exe as the download above.
4

Run it as Administrator

Right-click publish\IndoTweaks.exe → Run as administrator. Required — hardware sensors and system tweaks need an elevated token.

Questions

Before you ask

Is this safe to run?+
Every registry-level tweak backs up the original value before changing it, and offers to create a Windows System Restore point first. Nothing is a one-way door — Revert buttons exist for every tweak, and the Fortnite config editor keeps its own backup of your original GameUserSettings.ini.
Why does it need Administrator?+
Reading real CPU/GPU sensor data and writing to HKLM registry keys, the system timer resolution, and the TCP stack are all operations Windows restricts to elevated processes. Without it, IndoTweaks still opens, but the Tweaks tab disables itself rather than failing silently.
Will this get me banned in Fortnite?+
IndoTweaks only touches Windows OS settings and Fortnite's own GameUserSettings.ini — the same file the in-game settings menu writes to. It doesn't inject into, read, or modify the game process's memory, which is what anti-cheat systems actually watch for.
Why build from source instead of an installer?+
A tool that asks for admin rights and edits your registry is exactly the kind of thing you shouldn't have to trust blindly. Building from source means you (or anyone) can read every line before it runs.
The FPS numbers seem specific — are they guaranteed?+
No — they're rank-ordering estimates based on commonly cited community benchmarks for each setting, meant to help you prioritize which tweak matters most on your system. Actual gains vary by hardware.
